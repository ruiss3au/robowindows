ROBOWINDOWS WINDOWS 98 BENCHMARK

Run RWBENCH.EXE from Windows 98. It performs three ten-second phases:
CPU, memory, and off-screen GDI graphics. A compact window shows live metrics
and a small graphics preview updated at no more than ten guest frames/second.
The benchmark does not play sound or flash the full window. Close the window or
press Escape to stop it without stopping Windows.

The final result is displayed and saved as C:\RWBENCH.TXT.
Use only an experimental machine copy. Shut down Windows normally afterward.
