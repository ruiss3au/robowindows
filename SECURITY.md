# Security policy

RoboWindows is pre-release software and currently has no supported stable
version. Please do not use public issues for vulnerabilities that could expose
guest data, host files, credentials, or device identifiers.

Report a vulnerability through GitHub's private vulnerability reporting for
this repository. Include the affected revision, reproduction steps, impact, and
any suggested mitigation. Do not include proprietary guest media, product keys,
real device identifiers, or sensitive logs. If private reporting is not enabled,
open a public issue containing no vulnerability details and ask the maintainer
to provide a private contact channel.
