# Requirements Checklist

- [x] Backup source and destination machines are explicit.
- [x] Existing backups cannot be overwritten.
- [x] Guest disk verification is end-to-end, not archive-only.
- [x] App-running and unsafe-ID cases fail closed.
- [x] Proprietary ISO and key files are excluded.
- [x] Tracked tooling has no fixed tablet serial.
- [x] Existing script paths remain compatible.
- [x] GitHub blockers are explicit rather than silently guessed.
